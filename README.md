# contextual-workspaces

A [Noctalia](https://github.com/noctalia-dev/noctalia) plugin: named
app/workspace contexts for Hyprland. See
[`contextual-workspaces/README.md`](contextual-workspaces/README.md) for the
plugin itself.

## Using this as a plugin source

```sh
noctalia msg plugins source add contextual-workspaces git https://github.com/rnguyen03/contextual-workspaces
noctalia msg plugins enable rnguyen03/contextual-workspaces
```

`catalog.toml` at the repo root is auto-generated by CI on every push to
`main` — don't hand-edit it.
